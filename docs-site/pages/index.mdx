# wigtoken

Self-hostable usage aggregator for Claude Code. Tracks token consumption per user, machine, and model — comes with a built-in operator dashboard, a drop-in React widget for embedding live counters anywhere, and REST + SSE APIs. Prometheus integration is optional, not required.

## What it solves

If you're paying for Claude Code on a Max plan (or any plan) and want to know how much you and your team are burning, you have a few options:

- **Anthropic Console** — shows API spend, not Claude Code session spend.
- **ccusage** — single-user CLI, no team aggregation, no embedding.
- **CodeBurn** — pretty, but solo-only, hosted, no real-time embed.
- **wigtoken** — multi-user, self-hosted, real-time SSE, built-in dashboard + npm widget, optional Prometheus.

## Architecture in one diagram

```
Claude Code session(s)            wigtoken server                 Consumers
─────────────────────             ──────────────────                 ─────────
~/.claude/projects/   ──watch──►  chokidar + scanner                 GET /api/usage/totals
  *.jsonl                          │                                 GET /api/usage/timeseries
                                   ▼                                 GET /metrics  (Prometheus)
                                  SQLite (WAL)                       SSE /api/usage/stream
                                   │                                 SSE /embed/stream
                                   ▼                                  ↓
                                 Hono app  ───────────►  operator dashboard (/web)
                                                          npm @wigtoken-temp/widget
                                                          embed on wigtn.com etc.
```
